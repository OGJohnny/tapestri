# Tapestri

Tapestri is an AI-enhanced nonlinear creative writing environment designed for large-scale narrative development, worldbuilding, character tracking, and semantic story analysis.

Unlike traditional writing software, Tapestri treats stories as interconnected knowledge systems rather than isolated documents. Chapters, characters, timelines, locations, ideas, notes, and thematic concepts are visualized as a living narrative graph that evolves in real time.

## Core Features

- Interactive force-directed narrative graph
- AI-assisted semantic relationship analysis
- Dynamic character and emotional state tracking
- Narrative tension and arc detection
- Community clustering and thematic mapping
- Cognitive focus mode for contextual writing
- Temporal narrative analysis
- Incremental analytics architecture
- Hierarchical memory systems
- Real-time minimap navigation
- Semantic zoom and level-of-detail rendering
- Relationship dynamics and narrative propagation systems

## Philosophy

Tapestri is built around the idea that storytelling is not linear.

Characters influence themes.
Themes echo across timelines.
Worldbuilding affects emotional trajectories.
Narrative structures emerge from interconnected systems.

The goal of Tapestri is to make those hidden relationships visible and explorable.
